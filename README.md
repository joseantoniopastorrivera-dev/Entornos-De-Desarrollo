# Entornos de Desarrollo - 1º DAM

Repositorio dedicado a la configuración de entornos, prácticas, documentación y herramientas de desarrollo para el módulo de Entornos de Desarrollo de 1º de DAM (Desarrollo de Aplicaciones Multiplataforma).

## 📁 Estructura del Repositorio

El contenido se organiza de manera modular por Resultados de Aprendizaje (RA) y bloques prácticos:

* **`RA2-Instalacion-Configuracion-y-Automatizacion/`**: Instalación, análisis y configuración de Entornos de Desarrollo integrados (IDEs).
* **`RA3-Verificacion-Funcionamiento-Pruebas-Depuración/`**: Pruebas de software, depuración y verificación del correcto funcionamiento del código.
* **`ra4a-control-de-versiones-git-y-github/`**: Prácticas de control de versiones con Git, flujos de trabajo en GitHub y uso de herramientas de apoyo (incluyendo hoja de referencia rápida).
* **`ra4b-proyecto-fenix-refactorizacion/`**: Prácticas del Proyecto Fénix enfocadas en la refactorización de código limpio.
* **`ra5a-uml-a-codigo/`**: Ingeniería hacia adelante, transformación de modelos UML a código fuente.
* **`ra5b-codigo-a-uml/`**: Ingeniería inversa para la obtención de diagramas UML a partir de código.
* **`RA6.1a-Casos-de-Usos-Biblioteca/` & `RA6.1b-Casos-de-Usos-Hospital/`**: Modelado de casos de uso (relaciones include/extend y herencia).
* **`ra6-2a-diagrama-secuencia-cajero/` & `ra6-2b-diagrama-secuencia-vuelos/`**: Diagramas de secuencia para la modelización del comportamiento dinámico.
* **`ra6-3a-diagrama-actividades-soporte/` & `ra6-3b-diagrama-actividades-onboarding/`**: Diagramas de actividades para flujos de procesos.
* **`ra6-4a-diagrama-estados-expendedora/` & `ra6-4b-diagrama-estados-cerradura/`**: Diagramas de transición de estados.

## 🛠️ Entorno y Tecnologías

* **Herramientas e IDEs:** Visual Studio Code / Eclipse
* **Control de Versiones:** Git / GitHub / GitHub Desktop / Git Bash
* **Modelado:** PlantUML / Herramientas de diagramación UML
